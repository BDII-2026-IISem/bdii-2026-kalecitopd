# OdontoNova - Implementación en Oracle Database

Este directorio contiene la implementación del modelo de datos de **OdontoNova** adaptado a **Oracle Database**, manteniendo equivalencia estructural completa con el esquema original de PostgreSQL.

## 🗂️ Estructura del Esquema (10 Tablas)

1. **`pacientes`**: Gestión de pacientes con identificación única y estado activo.
2. **`odontologos`**: Registro de profesionales odontólogos y especialidades.
3. **`sillones`**: Control operativo de la disponibilidad de sillones odontológicos.
4. **`historias_clinicas`**: Información médica, antecedentes y alergias por paciente (Relación 1:1 con `pacientes`).
5. **`citas`**: Agendamiento de citas asociando paciente, odontólogo y sillón asignado.
6. **`planes_tratamiento`**: Agrupación de procedimientos recomendados a un paciente.
7. **`procedimientos`**: Catálogo general de servicios y procedimientos clínicos.
8. **`detalles_tratamiento`**: Relación N:M (Detalle/Líneas) entre planes de tratamiento y procedimientos.
9. **`sesiones_clinicas`**: Registro de ejecución efectiva de citas realizadas.
10. **`pagos`**: Transacciones financieras asociadas a los planes de tratamiento.

## 🛠️ Especificaciones Técnicas (Oracle)

* **Claves Primarias:** Uso de `NUMBER GENERATED BY DEFAULT AS IDENTITY`.
* **Tipos de Texto:** `VARCHAR2` para cadenas y `CLOB` para campos extensos de texto (`antecedentes`, `motivo`, `descripcion`).
* **Tipos Temporales:** `TIMESTAMP` para marcas de tiempo y `DATE` para fechas de nacimiento.
* **Campos Boleanos:** Implementados mediante `NUMBER(1)` con restricción `CHECK (is_active IN (0, 1))`.
